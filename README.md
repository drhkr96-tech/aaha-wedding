# Dr. Aarthi & Dr. Harish Kumar — Cinematic Wedding E-Invite

A mobile-first cinematic South Indian wedding invitation designed for GitHub Pages.

## Files

- `index.html` — page structure and wedding content
- `style.css` — luxury cinematic design and animations
- `script.js` — door opening, scroll reveals, effects and music button
- `assets/` — optional folder for background music or future assets

## GitHub Pages deployment

1. Create a new GitHub repository, for example `wedding-invite`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Click **Save**.
6. GitHub will provide your public Pages URL.

## Optional music

Place your legally owned/licensed audio file at:

`assets/music.mp3`

The floating ♪ button will then play/pause it. Browsers generally block automatic audio playback, so the visitor must tap the button.

## Customization

All main colors are defined at the top of `style.css` under `:root`.

No photograph assets are required for this version.
